# ソダテルモン（sodaterumon）

モンスター作品「ソダテルモン」のキャラクター素材を制作・整理しているリポジトリです。粘体・鱗体・牙体・翼体など10系統のモンスターについて、通常イラストとドット絵を同じ個体として対応づけています。

## ここで見られるもの

- [モンスター素材](assets/monsters/)：系統・個体別の画像と制作情報。
- [カタログ](assets/monsters/catalog.json)：215種の制作候補。予定数であり、215種すべての完成を意味しません。
- [制作状況](assets/monsters/manifest.json)：予定・生成・検査・保存確認を分けた記録。
- [素材の読み方](assets/monsters/README.md)：ファイルの対応関係と制作上の注意。

現在のリポジトリは素材制作段階で、起動して育成・対戦できるゲーム本体は含まれていません。画像や計画を、完成したゲーム機能として紹介しないようにしています。

## 素材を見る方へ

生成・加工の来歴は各個体のメタデータを参照してください。AI生成素材を含み、完成や権利確認が済んだものと未確認のものを区別しています。リポジトリの公開だけを、素材の自由な再配布や商用利用の許諾とは扱わないでください。この文書更新では利用許諾を追加・変更していません。
